# 屬靈導師｜讀經筆記 App

## 一、部署到 GitHub Pages（3 分鐘）
1. 在 GitHub 建立新的 repository（例如 `bible-notes`），設為 Public。
2. 把 `index.html` 和 `README.md` 上傳到根目錄（Add file → Upload files）。
3. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
4. 約 1 分鐘後開啟 `https://你的帳號.github.io/bible-notes/`。
5. 第一次使用，展開「AI 設定」貼上自己的 Gemini API 金鑰（到 aistudio.google.com 申請）。金鑰只存在使用者自己的瀏覽器。

> 提醒：不要把 API 金鑰寫進 index.html 再上傳，公開後會被他人盜用。

## 二、Google AI Studio（Build 模式）提示詞

請建立一個「屬靈導師」讀經筆記 app/web，繁體中文，手機優先並可切換平板與電腦版面，一個 index.html 可直接部署到 GitHub Pages。

**角色**：溫柔、扎根聖經的牧者型導師，服務華人基督徒。所有內容以經文為據，先觀察、再解釋、最後應用；不確定的背景或原文要明說，不捏造經文；不替讀者宣告「神一定要你…」，用邀請與提問帶領；教義維持歷史正統立場，有不同詮釋時簡短並列。

**模式一：一鍵生成**
- 輸入經文出處，可選貼上經文或今天的感動，可選深度：精簡（5 分鐘）、標準、深入（背景、原文詞彙、串連經文）。
- 輸出結構：經文摘錄、觀察、默想（神是怎樣的神／我是怎樣的人）、應用（今天能做的一個具體行動）、禱告（第一人稱 3–5 句）、本週一句話。
- 可儲存、複製、下載 .md、列印。

**模式二：引導式**（五步驟、進度條）
1. 選經文。
2. 觀察：導師提問（重複字詞、轉折詞、哪句讓你停下來），讀者自己寫。
3. 默想：看見神的面向與自己的光景。
4. 應用：選一件小而具體、有時間與對象的行動。
5. 禱告：用自己的話回給神。
- 每一步都有「請導師引導」：欄位空白時給 3 個針對經文的問題，不代答；有內容時先肯定一個優點、指出一處可更貼近經文、再追問一個問題（150 字內）。
- 最後可「直接整理」或「由導師潤飾」，潤飾時必須保留讀者原意與語氣。

**我的筆記**：本機儲存、查看、刪除、全部下載。

**品質要求**：沒有 API 金鑰時引導式仍可使用內建問題；錯誤訊息要說明原因與解法；介面支援深色模式、鍵盤操作、列印。
